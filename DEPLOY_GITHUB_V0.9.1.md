# Publicação no GitHub Pages — v0.9.1

1. Use o pacote `estudo-flex-languages-v0.9.1-github-raiz.zip`.
2. Extraia o conteúdo e envie os arquivos internos diretamente para a raiz do repositório.
3. Confirme que `index.html`, `sw.js`, `manifest.json`, `core/`, `components/`, `services/` e `css/` aparecem na primeira camada.
4. Aguarde a conclusão do workflow do GitHub Pages.
5. Abra `diagnostico-publicacao.html` e confirme que todos os arquivos retornam `OK 200`.
6. No primeiro acesso após a atualização, recarregue sem cache ou use uma janela privativa.

A versão 0.9.1 altera o schema local. O aplicativo remove automaticamente filas de revisão antigas que não consigam provar de qual atividade vieram.
