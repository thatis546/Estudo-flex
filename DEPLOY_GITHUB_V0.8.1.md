# Publicação no GitHub Pages — versão 0.8.1

1. Extraia o ZIP completo.
2. Abra a pasta `estudo-flex-languages-main-v0.8.1`.
3. Envie **o conteúdo interno dessa pasta** para a raiz do repositório `Estudo-flex`.
4. Confirme que `index.html`, `core`, `components`, `services`, `data`, `css`, `assets`, `sw.js` e `manifest.json` estão no mesmo nível.
5. Não envie somente o pacote de componentes sobre uma base incerta e não deixe arquivos 0.8.0 misturados.
6. Aguarde o GitHub Pages concluir a publicação.
7. Abra o site. A 0.8.1 limpa o cache antigo automaticamente. Caso a tela de recuperação apareça, use o botão “Limpar atualização antiga e recarregar”.

O diretório `backend` pode permanecer no repositório, mas o GitHub Pages não executa o servidor Node.js.
